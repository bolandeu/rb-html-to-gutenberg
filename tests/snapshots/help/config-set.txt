
 Usage: html_to_gutenberg config set [OPTIONS] {key} {value}

 Set a single, non-secret configuration value.

 Example: html_to_gutenberg config set provider.name github

╭─ Arguments ──────────────────────────────────────────────────────────────────────────────────────╮
│ *    key        <str>  Dotted config key, e.g. provider.name [required]                          │
│ *    value      <str>  New value (stored as a string). [required]                                │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
╭─ Options ────────────────────────────────────────────────────────────────────────────────────────╮
│ --json           Emit machine-readable JSON output.                                              │
│ --quiet          Suppress non-essential output.                                                  │
│ --help           Show this message and exit.                                                     │
╰──────────────────────────────────────────────────────────────────────────────────────────────────╯
